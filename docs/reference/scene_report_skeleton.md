# Copy the packaged scene report template

Copy the packaged scene report template

## Usage

``` r
scene_report_skeleton(path = "scene-report.Rmd", overwrite = FALSE)
```

## Arguments

  - path:
    
    Destination path for the `.Rmd` file.

  - overwrite:
    
    Logical. Overwrite an existing file?

## Value

The destination path, invisibly.
