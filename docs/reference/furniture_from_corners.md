# Axis-aligned object from two measured opposite corners

Axis-aligned object from two measured opposite corners

## Usage

``` r
furniture_from_corners(id, type, p1, p2, ...)
```

## Arguments

  - id, type:
    
    Passed to `furniture()`.

  - p1, p2:
    
    Numeric length-2 opposite corners `c(x, y)`.

  - ...:
    
    Further arguments to `furniture()`.

## Value

A one-row `furniture` tibble.
