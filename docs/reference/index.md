# Package index

## All functions

<!-- end list -->

  - `along_wall()` : Place an object against a wall, as it is measured
    in the field
  - `assumed_segment()` : Segment with an assumed (not measured)
    deflection
  - `coords_baseline()` : Convert baseline (rectangular coordinate)
    measurements to XY
  - `coords_polar()` : Convert polar (azimuth/distance) measurements to
    XY
  - `coords_triangulation()` : Convert triangulation measurements to XY
  - `death_scene_record()` : Structured death scene observation record
  - `evidence_log()` : Create an empty evidence log
  - `file_hash()` : SHA-256 hash of files
  - `furniture()` : Define a scene object (furniture, appliance, person)
  - `furniture_catalogue()` : Catalogue of object types with default
    height, colour and label
  - `furniture_footprint()` : Footprint polygons of scene objects
  - `furniture_from_corners()` : Axis-aligned object from two measured
    opposite corners
  - `furniture_table()` : Summary table of scene objects for reports
  - `impact_angle()` : Impact angle from a bullet defect's ellipse
  - `intersect_trajectories()` : Convergence of two trajectories
  - `log_custody()` : Record a custody event
  - `log_item()` : Add an evidence item to a log
  - `opening()` : A door or window segment for scene plots
  - `origin_zone()` : Possible origin of fire at assumed muzzle heights
  - `path_deflections()` : Deflection angles and joint consistency of a
    path
  - `plot_scene()` : Plot scene points as a simple sketch
  - `plot_trajectories()` : Plot trajectories in plan or elevation view
    with uncertainty
  - `plot_wall_elevation()` : Elevation view of one wall
  - `render_scene_3d()` : Render a 3D reconstruction of the scene
    (rayrender)
  - `render_scene_report()` : Render a scene report to Word, PDF and/or
    HTML
  - `report_footer()` : Provenance footer for generated reports
  - `room_rect()` : Build a rectangular room outline for scene plots
  - `scene_3d_widget()` : Interactive 3D scene widget (rgl / WebGL)
  - `scene_report_skeleton()` : Copy the packaged scene report template
  - `trajectory_2pt()` : Trajectory through two points on the bullet
    path
  - `trajectory_from_angles()` : Trajectory from angles measured at the
    defect (rod, laser or protractor)
  - `trajectory_from_defect()` : Trajectory from a single defect's
    ellipse on a vertical surface
  - `trajectory_obstructions()` : Which objects does a back-projected
    trajectory pass through?
  - `trajectory_path()` : Build a segmented trajectory through
    intermediate targets
  - `trajectory_table()` : Summarise one or more trajectories as a table
  - `wall_from_room()` : Wall segment of a rectangular room, ordered as
    seen from inside
