# forensicR: Crime Scene Documentation and Reconstruction Tools

Tools for crime scene investigators: scene mapping from field
measurements (baseline, triangulation, polar), shooting reconstruction
from bullet defects, structured evidence and custody logging, and
reproducible scene reports rendered to Word, PDF or HTML.
